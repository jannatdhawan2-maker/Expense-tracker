# 💰 Project Title: Expense Tracker Using C

## 📝 Project Description

The Expense Tracker is a simple, menu-driven application developed using the C programming language. It helps users record and manage their daily expenses in an organised manner.

The program allows users to add expenses by entering a description, selecting a category and providing the amount spent. It also provides options to view all recorded expenses, calculate the total expenditure and identify the highest expense.

The project uses **structures and arrays** to store expense details, **functions** to perform different operations, and **loops and switch statements** to control the program flow.

## 🎯 Objectives
1. 📌 To maintain a record of daily expenses.
2. 🛒 To categorise expenses such as Food, Travel, Shopping and Education.
3. 🧮 To calculate total expenditure.
4. 📊 To identify the highest expense.
5. 💻 To understand the practical application of C programming concepts.

## 🛠️ Technologies Used
- 💻 Programming Language: C
- ⚙️ Compiler/IDE: Dev-C++ or GCC
- 📚 Concepts: Structures, Arrays, Functions, Loops, Conditional Statements and Switch Case.

## ✨ Features
- ➕ Add new expenses.
- 📋 View all recorded expenses.
- 💵 Calculate total spending.
- 🏆 Find the highest expense.
- 🚪 Exit the application.

## 🎓 Conclusion

This project demonstrates how C programming can be used to solve a real-life problem. It provides a basic way to manage daily expenses and helped in understanding important programming concepts such as structures, arrays, functions and loops.

⚠️ **Limitation:** Expenses are stored temporarily in memory and are not saved permanently after the program exits.
